# PDFGlide Features

## 1. PDF Organization Tools

| Feature | Deskripsi | Priority | Status |
|---------|-----------|----------|--------|
| **Merge PDF** | Gabungkan beberapa PDF menjadi satu dokumen | 🔴 High | Planned |
| **Split PDF** | Pisahkan halaman atau set halaman menjadi file PDF independen | 🔴 High | Planned |
| **Organize PDF** | Sortir, hapus, atau tambah halaman sesuai keinginan | 🟡 Medium | Planned |
| **Rotate PDF** | Rotasi PDF sesuai kebutuhan, bisa multiple sekaligus | 🟡 Medium | Planned |
