# PDFGlide Documentation

## Overview
PDFGlide adalah aplikasi web untuk memproses berbagai format file termasuk PDF, gambar, dokumen Word, dan Excel.

## Quick Start
1. Clone repository
2. Setup backend: `cd backend && pip install -r requirements.txt`
3. Setup frontend: `cd frontend && npm install`
4. Run backend: `uvicorn app.main:app --reload`
5. Run frontend: `npm run dev`
6. Akses http://localhost:3000
